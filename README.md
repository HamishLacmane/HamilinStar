# Hamilin Star

Hamilin's food-rating system — part of the Hamilin brand family. Currently a placeholder shell only.

## Status

Deliberately undecided, not yet built:
- **Colours** — not chosen. `styles.css` uses a neutral grey placeholder, not a real palette pick.
- **Data source** — "some view of filterable export," but where the ratings data actually comes from (Airtable, NocoDB, a static file) hasn't been decided. Don't build the filterable view until this is settled.

What exists now is just enough to have the domain point somewhere real: a "coming soon" page, no framework, no build step, deploys to GitHub Pages with zero configuration once wired up.
